# 可视化大屏预览

纯静态可交互页面，脚本、样式与素材均已内嵌。

- [全国人口统计总览](./population.html)，默认首页。
- [智慧工厂](./factory.html)。
- [智能巡检运营调度](./inspection.html)。

## GitHub Pages

在仓库 Settings → Pages 选择 Deploy from a branch，分支 master，目录 /(root)，保存后等待部署完成。

页面数据为视觉演示数据。支持 WebGL 的桌面浏览器可查看完整三维效果。

## 素材与许可

D3.js 7.9.0 (ISC)、Three.js r160 (MIT)，保留内嵌版权声明。地理数据来自阿里云 DataV 和 Natural Earth；地球纹理来自 Three.js 官方示例；巡检地形来自 Esri。工厂模型和人口页眉素材由 ImageGen 生成。
