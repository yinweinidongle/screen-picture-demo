智慧工厂支持拖动旋转、滚轮缩放、建筑点选、全景、自动环绕，以及菲涅耳轮廓光夜景。日夜切换采用从左向右的扫光过渡。页面脚本、样式与素材均已内嵌。GLB 经 Khronos 验证，0 错误、0 警告。

页面数据为视觉演示数据。三维厂区按单张参考图重建，未提供原始 CAD 或三维资产；背面与不可见细部为合理补建。

## 部署

GitHub Pages 使用 master 分支根目录，提交后自动更新。

## 素材与许可

D3.js 7.9.0 (ISC)、Three.js r160 (MIT)，内嵌版权声明保留。地理数据来自阿里云 DataV 和 Natural Earth；地球纹理来自 Three.js 官方示例；巡检地形来自 Esri。人口页眉与工厂降级图片由 ImageGen 生成。实时工厂几何由程序建模。
