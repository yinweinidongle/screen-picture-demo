The screens were reconstructed from user-provided reference images for an interactive visual demonstration. No original CAD files or original reference models were supplied; hidden structure and dimensions are illustrative. Reference images themselves are not included or relicensed. The active wind page uses the project's own VIZLAB branding. Earlier recorded previews may show prior reference branding; such marks are not licensed by this repository.

A source inventory with file checksums is maintained in [assets/manifest.json](assets/manifest.json). Before redistributing these assets in a separate product, verify the relevant source terms or replace the entries marked `review-required` with appropriately licensed alternatives. To report an attribution problem, open a focused [issue](https://github.com/yinweinidongle/screen-picture-demo/issues/new?template=bug.yml) with the source and affected path; do not include private material.
