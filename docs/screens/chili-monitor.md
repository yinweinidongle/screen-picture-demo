# 衡水市辣椒产业大数据分析平台

大屏以 1651 × 953 为设计尺寸，随窗口等比缩放。中央展示一株成熟辣椒的三维模型，两侧展示企业与地块的模拟监测数据。模型用于观察叶片、果皮和分枝，右侧生育阶段表示所选地块的记录。

## 操作

- 拖动植株旋转视角。用 Tab 聚焦植株后，方向键可水平或垂直旋转，Home 键返回初始视角。
- 选择企业和地块可更新气象读数、生长率及阀门状态。浇水和 A 至 D 桶开关在本次页面会话内按地块保存。
- 点击出库、入库图例可切换对应柱组。仓库与出入库图表使用固定的市级示例数据。监控区两侧可切换同一静态场景的示意视角。
- 系统启用减少动态效果时，植株停止自动摆动，保留手动旋转。缺少 WebGL 时可继续查看数据面板。

## 成像与素材

Three.js 使用曲线和参数曲面生成枝干、叶片、花萼与果实。GLSL 根据叶面朝向控制透光，根据果皮曲率和观察角度计算高光。亮部经过降采样和模糊后与原始画面合成。叶脉、果皮网格与文字仍在清晰的图层中呈现。[植株材质与几何](../../src/screens/chili-monitor/plant.js) · [Bloom](../../src/screens/chili-monitor/plant-bloom.js)
