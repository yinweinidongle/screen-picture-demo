# 望舒站 · 夜行进站观测

在月环线 02 站台，跟随 WS 700 完成一段 19 秒的模拟进站。半透明侧栏叠在全视口三维场景上。左侧是车速曲线和制动减速度柱图，右侧是 02 站台位置图与全息扫描环。手机默认收起仪表，点页头的仪表按钮即可展开。[打开大屏](https://yinweinidongle.github.io/screen-picture-demo/wangshu-station.html)

## 回看进站

- 初次打开从 6.6 秒的站台低位镜头开始，随后按完整序列循环。开启系统的「减少动态效果」时，画面停在首帧，点播放即可继续。
- 打开页头的镜头菜单，可直接跳到穹顶俯移、站台低位跟拍、沿车窗侧移或绕车头升起。在左侧速度曲线上拖动可逐段查看扫描，也可打开带有 `?t=9.4` 的地址停在指定秒数。[回看车头扫描](https://yinweinidongle.github.io/screen-picture-demo/wangshu-station.html?t=9.4)
- 点击「自由观察」会停住时间。拖动旋转，滚轮或双指缩放。「返回运镜」恢复当前时刻的摄影机视角。空格切换播放，左右方向键在画面上每次移动 0.25 秒。
- 环境音默认关闭，可在页头打开。切到后台时画面和声音会暂停。设备无法创建 WebGL 2 场景时，会显示实拍自该模型的静帧，镜头选择和遥测曲线仍可操作。

## 数据和场景

列车走过 112 米，第 17.5 秒停稳。速度取自位移动画所用制动曲线的一阶导数，千米每小时与米每秒按 3.6 换算。减速度柱图取上述速度对时间的变化率，峰值约为 1.10 m/s²。站台示意图显示当前已行驶距离占比。扫描百分比表示从 8.25 秒到 16.75 秒的特效时间进度。所有数值均来自本地进站模拟。

[镜头与制动曲线](../../src/screens/wangshu-station/sequence.js)定义摄影机和时间采样。[场景](../../src/screens/wangshu-station/world.js)播放 GLB 内的 Blender 动画并渲染湿石倒影。[着色器](../../src/screens/wangshu-station/phase.js)让同一条波前依次扫过列车和右侧站台。[操作与仪表](../../src/screens/wangshu-station/app.js)共用这一时钟。
